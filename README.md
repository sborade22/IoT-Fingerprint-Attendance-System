# Fingerprint Attendance & Absentee Report via Telegram

## Project Overview
This is an IoT-based Fingerprint Attendance System that records student attendance using a fingerprint sensor and sends attendance reports through Telegram.

## Developed By
Sakshi Borade

## Technologies Used
- Python
- Raspberry Pi
- Fingerprint Sensor
- Telegram Bot API
- IoT

## Key Features
- Fingerprint-based attendance marking
- Automatic attendance recording
- Present and absent student reports
- Telegram notifications
- Real-time attendance updates

## Project Files
- `s.py` – Python source code
- `Sakshi_Borade_IoT_Project_Portfolio_Revised.pdf` – Project documentation

## Conclusion
This project demonstrates how IoT and Python can be used to automate attendance management and generate attendance reports through Telegram.
